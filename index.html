03

Choosing an API Gate Valve Supplier

Many industrial projects specify API standards. Buyers should identify the exact standard listed in the project specification rather than selecting a valve based only on the term “API.”

An API gate valve supplier should identify the applicable standard and confirm the supporting technical documentation.

API 600 Gate Valves

API 600 covers steel gate valves with flanged and butt-welding ends and bolted bonnets. It is used in petroleum, petrochemical, and related industrial applications.

For an API 600 purchase, confirm the required size range, pressure class, materials, trim, end dimensions, testing, and project documents.

API 602 Gate Valves

API 602 covers compact gate, globe, and check valves for petroleum and natural gas industry applications and is commonly associated with smaller valve sizes.

Confirm that API 602 matches the project piping specification before placing the order.

API 6D Gate Valves

API 6D is used for pipeline valve applications. Its scope differs from API 600, so the two standards should not be treated as interchangeable. API currently lists Specification 6D for pipeline valves.

The applicable standard depends on the project requirement, line service, pressure rating, and valve design.

04

Materials Matter in Gate Valve Selection

Valve material must match the service conditions. Material selection covers the body, bonnet, stem, trim, bolting, packing, and gasket requirements.

Carbon steel is used for many industrial services. Stainless steel and alloy materials may be selected when corrosion resistance, temperature, or process conditions require them.

The main material checks include:

  • Body material
  • Bonnet material
  • Stem material
  • Seat material
  • Trim
  • Bolting
  • Packing
  • Gasket requirements

Material grades must match the project specification. Material records may also form part of the final documentation package.

For critical industrial orders, review material selection together with pressure, temperature, and process media.

05

Pressure Class and End Connection

Pressure class is one of the first specifications required for a gate valve quotation.

The required class depends on the piping system and service conditions. Ordering the wrong rating can create installation and project problems.

End connection is also important. Depending on the design and project requirement, buyers may need:

  • Raised-face flanges
  • Ring-type joint flanges
  • Butt-weld ends
  • Socket-weld ends
  • Threaded ends

Dimensional requirements must match the applicable valve and piping standards. ASME B16.34 covers pressure-temperature ratings, dimensions, materials, examination requirements, testing, and marking for covered valves.

Quality Control and Valve Testing

A China gate valves manufacturer needs a defined quality-control process covering materials, machining, assembly, testing, and final inspection.

Incoming Material Checks

Materials are checked against the approved specification and purchase requirements.

Machining and Assembly Checks

Critical dimensions, machining quality, alignment, sealing surfaces, and assembly are inspected during production.

Pressure and Seat Testing

Confirm the required pressure test standard and acceptance criteria for the project. API 598 is an established API standard for valve inspection and testing.

Final Inspection

The final check can cover:

  • Valve identification
  • Size and pressure rating
  • End dimensions
  • Appearance
  • Operation
  • Marking
  • Packing
  • Required documentation

Larger projects often include third-party inspection or project-specific inspection plans.

How to Send an RFQ to a Gate Valve Supplier

A detailed RFQ gives the supplier the information needed for an accurate quotation.

Provide:

Valve type + size + pressure class + material + end connection + medium + temperature + quantity + standard + actuation requirements

For example:

Gate Valve, NPS 8, Class 300, carbon steel body, RF ends, hydrocarbon service, manual operation, quantity 40, API 600.

Request confirmation of the proposed configuration, test requirements, delivery terms, and documentation with the quotation.

Applications of Industrial Gate Valves

Gate valves are mainly used for isolation rather than frequent throttling.

Oil and Gas

Oil and gas projects often specify pressure class, material grade, end connection, testing, and project documentation in detail.

Petrochemical Plants

Petrochemical service requires material and sealing selection based on the process medium, pressure, and temperature.

Power Generation

Power projects can involve water and steam service, making pressure-temperature requirements and material selection important.

Industrial Piping

Manufacturing plants and utility systems use gate valves for line isolation where the valve design matches the service conditions.

The final valve selection must follow the actual operating conditions and engineering specification.
